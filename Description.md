# TheraVR
VR project written using Aframe tool at [Aframe.io]. This is a therapeutic VR experience, which you can join with multiple users using the same link. In addition to mic and movement controls for the users.
The user can look around by rotating their phone or their head if they are in VR mode with full gyroscopic look around. There is a small reticle to use for interaction with your surroundings such as going through portals to enjoy the environment provided

Please enjoy
